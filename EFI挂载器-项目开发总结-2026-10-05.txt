二、2026-10-05 已完成的功能开发
================================
1. EFI / ESP 磁盘识别
- 自动扫描当前 Mac 上的磁盘和分区
- 自动识别 EFI / ESP 分区
- 区分内置硬盘和外置设备
- 显示磁盘名称、物理磁盘、EFI 分区、磁盘总容量、EFI 分区容量
- 显示分区类型、EFI 当前状态、EFI 挂载路径

2. 一键挂载 EFI
- 图形界面直接挂载 EFI
- 支持内置硬盘 EFI、外置 USB EFI、移动硬盘 EFI
- 支持可识别的 EFI / ESP 分区
- 挂载成功后自动更新状态

3. EFI 卸载
- 支持直接卸载已经挂载的 EFI
- 卸载后自动更新磁盘状态

4. 自动刷新
- EFI 挂载或卸载后自动更新磁盘列表
- 提供手动刷新按钮
- 无需退出程序即可重新扫描磁盘状态

5. EFI 详细信息
双击磁盘列表项目可以打开独立的 EFI 详细信息窗口。
显示：类型、磁盘名称、物理磁盘、EFI 分区、磁盘容量、EFI 容量、分区类型、当前状态、挂载路径。
说明：详细信息窗口当前布局已经确认正常，后续开发不要随意修改。

6. 一键复制挂载路径
EFI 挂载成功后，可以直接复制 EFI 挂载路径，方便在 Finder、Terminal 或其他工具中访问。

7. 软件图标

十一、后续开发路线
===================
后续建议不要直接修改 v1.2.0，而是从新的开发版本开始：
v1.2.0 → v1.3-dev → 开发与测试 → v1.3.0

第一阶段：磁盘管理增强
----------------------
1. 更完善的磁盘信息
- 磁盘型号
- 磁盘接口
- 连接类型
- 磁盘序号
- 分区数量
- GPT / MBR 信息
- APFS / HFS+ / FAT32 等文件系统信息

第二阶段：EFI 安全功能
----------------------
2. EFI 备份
建议增加“备份 EFI”，流程：
挂载 EFI → 备份 EFI → 选择保存位置 → 自动生成备份文件夹
可以记录日期、时间、磁盘名称、EFI 信息。

3. EFI 恢复
与备份配套增加“恢复 EFI”，允许选择以前的 EFI 备份进行恢复。

4. EFI 快照
可以增加“EFI 快照”，例如：
- 2026-10-05-原始
- 2026-10-05-修改前
- 2026-10-05-修改后

第三阶段：OpenCore / Hackintosh 增强
------------------------------------
5. OpenCore EFI 检测
自动检测：
- EFI/OC
- EFI/BOOT
- EFI/Microsoft
并判断 EFI 是否具有典型 OpenCore 结构。

6. OpenCore 配置检查
检查：
- config.plist 是否存在
- OC 文件夹是否存在
- BOOTx64.efi 是否存在
- OpenCore.efi 是否存在
- Drivers
- Kexts
- Resources
- Tools

7. EFI 完整性检查
例如：
EFI 完整性检查
BOOT ✓
OC ✓
config.plist ✓
OpenCore.efi ✓

第四阶段：外置 EFI 兼容性增强
------------------------------
实际开发过程中曾遇到某些外置 EFI 分区无法通过普通 diskutil mount 挂载，但可以通过 mount_msdos 成功挂载。
未来可以设计：
正常 diskutil mount → 失败 → 自动检测 EFI 文件系统 → 尝试备用挂载方式 → 成功
并向用户显示明确结果。

第五阶段：错误提示增强
----------------------
统一错误提示。
例如：
EFI 挂载失败

可能原因：
• EFI 分区文件系统异常
• 分区当前正在使用
• 系统权限不足
• 文件系统需要检查

错误代码：
xxxx

第六阶段：权限管理继续优化
----------------------------
当前权限策略：
挂载：需要管理员权限。
全部挂载：需要管理员权限。
全部弹出：需要管理员权限。
单独卸载：不要求管理员密码。
未来增加备份、恢复、修复等功能时，继续保持权限边界清晰。

第七阶段：界面增强
------------------
未来可以考虑：
- 更漂亮的磁盘图标
- EFI 状态图标
- 挂载 / 未挂载视觉区分
- 更明显的操作按钮
- 空磁盘状态提示
- 无 EFI 时的提示页面
- 加载状态
- 操作成功提示
- 操作失败提示

原则：
不要破坏目前已经确认正常的首页和详细信息窗口。
