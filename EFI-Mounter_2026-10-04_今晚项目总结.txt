==================================================
三、今晚修正并确认的程序逻辑
==================================================

1. 自动刷新按钮闪烁问题已修复

之前 refresh() 开始时曾强制：
mountAllButton.isEnabled = false

导致程序每 3 秒刷新时“一键挂载”按钮闪烁。

现在已经删除这条强制禁用逻辑。

最终逻辑是在扫描完成后根据实际状态判断：

hasMounted = list.contains { $0.isMounted }
hasUnmounted = list.contains { !$0.isMounted }

然后：
mountAllButton.isEnabled = hasUnmounted
unmountAllButton.isEnabled = hasMounted

用户实际测试确认：
“一键挂载”按钮不再闪烁，自动刷新正常。

2. 权限模型最终确定

单个挂载：需要管理员授权。
单个推出：不需要管理员授权。
一键挂载：整个批量操作只进行一次管理员授权。
一键推出：不需要管理员授权。

这是最终确认过的设计，不应在没有明确需求的情况下重新修改。

3. NSWorkspace 自动刷新

已经修正 NSWorkspace 通知释放相关问题，并保留工作区状态变化自动刷新机制。

八、今晚讨论的许可证问题（重点）
==================================================

最初项目 README 使用的是：
Apache License 2.0

这个许可证当时是用户随手选择的。

经过今晚讨论，明确认识到 Apache License 2.0 的特点：

- 允许免费使用
- 允许修改
- 允许二次开发
- 允许商业使用
- 允许商业发布
- 不要求衍生商业产品必须开源

因此 Apache 2.0 不符合用户最终确定的长期目标：

“现在免费开源，以后允许自己收费，但不希望别人直接拿代码卖钱做商业使用。”

==================================================
十、v1.2.0 计划中的非商业许可证目标
==================================================

目标是：

“免费开源 + 允许非商业使用 + 限制未经授权的商业使用 + 保留作者未来收费和商业授权的权利。”

计划允许：

- 免费获取源码
- 个人使用
- 教育用途
- 研究用途
- 学习和查看源码
- 修改源码
- 自行编译
- 自行运行
- 非商业使用

计划禁止未经授权的：

- 商业使用
- 销售
- 收费分发
- 将代码直接集成到收费商业产品
- 将项目包装成商业产品进行盈利
- 其他未经授权的商业利用

商业使用需要获得版权所有者单独授予的商业授权。

版权所有者保留：

- 商业授权权利
- 未来推出收费版的权利
- 未来推出 Pro 版的权利
- 未来推出商业版的权利

==================================================
十一、为什么不修改 v1.1.1
==================================================

v1.1.1 已经按照 Apache License 2.0 正式发布。

Apache 2.0 授予的历史版本授权不能因为以后修改 README 或 LICENSE 就简单地追溯收回。

因此正确的版本策略是：

v1.1.1 及以前：
Apache License 2.0

v1.2.0 及以后：
EFI-Mounter Non-Commercial License 1.0

也就是说，两个授权阶段并存：

历史版本保持原授权。
新版本采用新的授权方式。
